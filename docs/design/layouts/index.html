Modelos de layout do GIPE

Seis propostas para a casca do app (menu, cabeçalho e rodapé) e o dashboard. Cada uma tem tema claro e escuro (botão no cabeçalho) e versão para celular. Os dados são de exemplo.

  • Modelo A: Planta do pátioAsfalto, tinta de demarcação e números estampados. O dashboard é o pátio visto de cima, com a entrada rápida por placa no topo.
  • Modelo B: Sinalização viáriaPlacas de trânsito brasileiras. O menu é um pórtico com placas penduradas e as vagas livres aparecem como uma placa de destinos.
  • Modelo C: Mosaico densoMódulos riscados por filetes, abas vermelhas e tipo pequeno. Mais informação por tela, para quem opera o dia todo.
  • Modelo D: Quadro de partidasLetras que giram como num quadro de estação. O pátio vira uma lista de partidas, com situação em cores e um único momento de movimento ao carregar.
  • Modelo E: Painel de LEDLetreiro da entrada da garagem. Cada vaga é um ponto aceso ou apagado, a letra é de pixel grosso e o menu é um teclado de totem.
  • Modelo F: Quadro de chavesA guarita do manobrista. Cada veículo é uma chave pendurada num gancho numerado, e tocar na chave abre os dados e a saída.
